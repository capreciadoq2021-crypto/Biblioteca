## Alcance documentado

La documentación describe el sistema tal como está implementado:

- Consulta de libros (listado, detalle y colecciones por categoría).
- Gestión completa de autores (crear, consultar, editar y eliminar).

Las funciones que aparecen en el menú pero aún no existen (préstamos, socios, gestión de libros y categorías, inicio de sesión) se señalan en cada documento como **trabajo futuro**.
